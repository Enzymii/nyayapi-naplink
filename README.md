# nyayapi-naplink

基于 NapLink 的 QQ 群/私聊机器人，支持常用娱乐指令与群聊互动。

## 指令

### `/ping`、`.ping`

- **说明**：测试 Bot 是否在线
- **参数**：无
- **适用范围**：群聊 / 私聊

### `/jrrp`、`.jrrp`

- **说明**：查询今日人品值（1–100），每人每天固定一次，同一天内重复查询结果不变
- **参数**：无
- **适用范围**：群聊 / 私聊

### `/r`、`.r`

- **说明**：掷骰，支持加减乘除与括号
- **参数**：
  - `表达式`（可选）：骰子写法 `NdM` 表示 N 个 M 面骰；省略时默认 `1d100`
  - 骰子数量 1–32，面数 1–512
  - 不支持嵌套骰（如 `2d6d4`）
- **适用范围**：群聊 / 私聊

### `/c`、`.c`

- **说明**：从多个选项中随机抽取
- **参数**：
  - `数量`（可选）：抽取个数，默认为 1；须为正整数且不超过选项总数
  - `选项…`：用空格分隔的候选项，至少 1 个，最多 100 个
- **适用范围**：群聊 / 私聊

### `订阅远行商人`

- **说明**：订阅洛克王国远行商人商品提醒（需管理员开启该功能）
- **参数**：
  - `关键词…`（可选）：空格分隔的商品关键词；省略时查看当前订阅
- **适用范围**：仅群聊
- **补充**：
  - Bot 每天 8:10、12:10、16:10、20:10 自动查询商店
  - 商品名 **包含** 关键词即视为命中，Bot 在群内 @ 对应订阅者

## 群聊被动行为

### +1 复读

- **触发**：连续 4 条不同用户发送的相同纯文本消息
- **行为**：Bot 复读该文本一次；同一轮不会重复复读

### 语气词复读

- **触发**：单条消息为 5 个及以上相同语气字符（如「啊」「哈」「喵」等）
- **行为**：Bot 复读该消息

### 贴表情

- **触发**：@Bot，消息以「贴表情」开头，并附带 emoji 或 QQ 表情
- **参数**：
  - 可回复某条消息，作为点赞目标；未回复时对当前消息点赞
- **行为**：Bot 对目标消息依次点赞对应表情
